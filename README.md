# Netflix Movies and TV Shows EDA
Netflix Movies and TV Shows Exploratory Data Analysis Cleaning and Visualization using Python.


## Project Overview

This project explores the Netflix Movies and TV Shows dataset using Python and Exploratory Data Analysis (EDA) techniques. 

The project focuses on:
- Data Cleaning 
- Handling Missing Values
- Feature Engineering
- Data Visualization
- Extracting Insights from the dataset 

---

## Dataset Information
## Dataset
[Netflix Movies and TV Shows](https://www.kaggle.com/datasets/anandshaw2001/netflix-movies-and-tv-shows)

- Rows: 8807
- Columns: 13
- Unique Values Analyzed: 8790

---

## Key Insights

- Netflix contains more Movies than TV Shows
- The United States produces the most Netflix content
- Drama and International Movies are among the most common genres
- Most TV Shows contain only one season
- Movie durations between 90 and 97 minutes are very common
